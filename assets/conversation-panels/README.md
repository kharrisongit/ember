# Conversation panel artwork

Generated with the built-in image_gen tool on 2026-09-28. These are flat illustrated game interface panels, not environmental backdrops. The Millwood panel was the style/layout reference for the other nine designs. Each final image is encoded as WebP without cropping or recoloring.

The conversation renderer uses a filled nine-slice border image to keep the corners proportional across phone, landscape and tablet layouts. Live lighting and star twinkles are separate animation layers.
