# Broken wagon

`broken-wagon.png` is an 80 × 56 transparent game prop generated with the built-in
image tool from the existing Forgewick drinks-cart sprite as a style reference.
Prompt: an empty wooden wagon with left-facing shafts, no canopy or goods, and
one visibly broken wheel with missing rim and loose spokes, matching the game's
coarse pixel grid, brown palette, outline weight and elevated camera angle.
The result was cropped to alpha bounds and resized with nearest-neighbor sampling.
It is used only for Oswin's Thornwell roadwork and leaves when the road opens.
